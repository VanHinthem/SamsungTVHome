# Versie 0.3.0

- Instellingen > HDMI-namen: eigen naam per poort, maximaal 30 tekens. Leeg bewaren herstelt de standaardnaam; het poortnummer blijft zichtbaar. Alleen aangesloten ingangen verschijnen op Home. Namen blijven lokaal opgeslagen.
- Houd OK op een Home-app 650 ms ingedrukt om te ordenen. Links/rechts verplaatst; OK bewaart; Terug annuleert. Verlaten van de app annuleert een nog niet bewaarde verplaatsing. Kort OK opent de app bij loslaten. De bestaande editor blijft beschikbaar.

Validatie: 22 model/artworktests, 39 browsercontroles en 7 aanvullende controles voor kort/lang OK, verplaatsen, bewaren en annuleren geslaagd. Het tv-toetsenbord en lang indrukken op de fysieke afstandsbediening moeten nog zichtbaar worden bevestigd.
